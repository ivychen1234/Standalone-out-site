Publishing

Embedding Constraint

The frame can host the world, but it cannot rewrite the browser identity.

你先前指定的 `HTCVRSDET` user agent 是測試環境的重要條件，但 GitHub Pages 上的靜態頁面無法主動覆寫使用者瀏覽器的 user agent。 如果要保證 dev world 正常載入，仍需要從 Playwright、瀏覽器外掛、代理層，或使用者端裝置本身設定來處理。
